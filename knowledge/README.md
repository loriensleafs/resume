# Knowledge

What the resume chat may answer from, besides `resume.yaml`. The rules are in [SPEC-knowledge](../spec/SPEC-knowledge.md).

- `deep-dives/<id>.md`: one piece of Peter's work in his own words, written in the third person.
- `logistics.yaml`: Peter's answers about remote work, location, availability and target roles.

An entry reaches the chat only after Peter approves it: `status: approved` plus the date. Run `bun run knowledge` to see exactly what the chat sees.
