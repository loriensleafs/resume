Chat input: send button states

The send button sits inside the input, at its right end, with no box around the two; “Answers for” stays underneath. Each input is drawn at the chat column’s width.

1. Empty

Send is off until there is a question.

2. Ready

A question is typed; Send is on. Enter sends, Shift+Enter adds a line.

3. Answering

While the answer streams in, Send becomes Stop: a plain square, with a progress ring turning on the button’s border. The next question can be typed.

4. Answering, a question waiting

Enter during an answer queues the new question. It waits above the input with a clock and sends when the answer finishes. × removes it. In an empty input, the Up arrow key brings it back into the input and off the queue.

5. Stopped

The visitor stopped the answer. What arrived stays, marked as stopped; Send is back.

6. Offline

Send becomes Queue. A queued question waits above the input with a clock and sends when the connection returns. × removes it; in an empty input, the Up arrow key brings it back.

7. Error

The question stays where it was asked, and the error takes the answer’s place. Try again resends it; Edit question puts it back in the input. The input stays free for a new question.
