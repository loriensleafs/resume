Highspot

Dec 2024 – Aug 2026

Sr. Software Development Engineer, Polar UI design system team, Seattle, WA

  • Led the organization-wide effort to build the polar-ui MCP server, the design system’s contract for AI coding agents, so agent-written UI follows the design system, including complex components such as the data table. It worked alongside the Figma MCP and became a standard part of every Cursor and Claude Code setup for front-end work, used by ~100 people across all application teams, design, and product.
  • Introduced many of the team’s AI development standards: spec-driven development, shared skills and agents checked into the repo, agent context files (CLAUDE.md, AGENTS.md), and rules that keep agents on Polar UI components.
  • Designed and rolled out an agent workflow system for the platform team, built in TypeScript on Bun: specialist agents and skills turn specs into dependency-mapped plans, where plans and tasks both carry dependencies, so up to 4 developers and their agents know which work is unblocked, claimed, or safe to run in parallel.
  • Used that system to build two major components: a streaming Markdown component, and a TanStack-based data table, built after an AG Grid Enterprise license was blocked and defined by 21 specs and 189 requirement documents.
