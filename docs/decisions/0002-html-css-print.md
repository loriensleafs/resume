# Design the resume in HTML and CSS, printed to PDF by Chrome

Peter wanted a cleaner, more modern design than Google Docs allows. Google Docs offered only two weights of Google Sans Flex, ignored literal tab characters, and limited spacing control. HTML and CSS give a real type scale, a spacing scale and print rules. Chrome prints the page to PDF.

Decided 2026-10 by Peter.

Considered: keep Google Docs (rejected for the limits above); a resume builder service (rejected: less control, and the source would not live in git). The older Google Doc in Drive is no longer the source.
