# The build also makes Word and text documents

Some application portals and recruiters ask for Word, and application forms ask for pasted text. Both come from the resume source, so they cannot drift from the PDF the way the old Google Doc did. The Word file uses Arial because recruiters' machines do not have Google Sans Flex; the PDF keeps the designed typography. The text file has no hard wraps and uses `-` bullets.

Decided 2026-10-26 by Peter (Word and text); the Arial font was the implementer's choice, recorded so nobody "fixes" it to Google Sans Flex.

Evidence: [research 02](../research/02-ats-file-formats.md).
