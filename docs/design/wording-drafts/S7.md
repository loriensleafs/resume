# S7: the font file format

## Draft

The site serves Google Sans Flex as one **WOFF** file: `/fonts/google-sans-flex-latin.woff`, 45,152 bytes.

- `scripts/site-fonts.ts` cuts it from the variable font, Google Sans Flex 5.000 in google/fonts at commit `bd8f81d`, checked by its SHA-256. The cut is deterministic: two runs give the same bytes.
- It keeps Google Fonts' "latin" characters and one variation axis, weight, from 400 to 700. Every other axis is pinned at its default (optical size 18, width 100, slant 0, roundness 0). Google Fonts pins them in the same way for the design system's own request, `family=Google+Sans+Flex:wght@400..700`. At weights 400 and 700, every character has the same advance as in Google's own files, and every outline but one is the same (that one moves by 1 unit of 2000).
- `src/site/styles/fonts.css` gives the file to the family that the tokens name, with `font-weight: 400 700` and `font-display: swap`, the design system's own setting. It is committed in `public/fonts/` with its license, `OFL.txt`, and the build copies both.
- Chrome loads the file and draws the text with it, at weight 400 and 600 (checked 2026-10-27).

### The choice for Peter's review

SPEC-site says that WOFF2 needs an encoder package. A check on 2026-10-27 found that it does not. WOFF2 lets a file store its glyph tables without their transform (transform version 3, "the null transform", in the WOFF2 specification), and Bun has Brotli built in. A throwaway prototype packed the same cut that way: 37,896 bytes, and Chrome loaded it and drew weights 400, 600 and 700 from it.

| Format | Size | New package | What changes |
|---|---|---|---|
| WOFF (built) | 45,152 bytes | None | Nothing |
| WOFF2, written by `scripts/site-fonts.ts` with Bun's Brotli, glyph tables untransformed | about 37,900 bytes (−16 %) | None | The script writes WOFF2; the CSS says `format("woff2")`; the test reads WOFF2 |
| WOFF2 with the glyph transform, from an encoder package | a little smaller again (not measured) | One, with Peter's approval | The same, through the package |

For comparison: Google Fonts serves 51,004 bytes of WOFF2 for the same request, because its file keeps the whole weight range, 1 to 1000.

Recommendation: WOFF2 written by the script with Bun's Brotli. It is 7 KB smaller on every first visit and needs no package. Every current browser reads WOFF2 (Safari since version 12); only Chrome was checked here. On a slow 4G link, 7 KB is about 35 ms.
